# nocfo-explorer

A yazi-inspired terminal explorer for [NoCFO](https://developers.nocfo.io)
files and folders: browse the folder tree, preview files, and run the common
file operations — rename, move, copy, delete, new folder — plus search and
multi-select, straight against the NoCFO REST API.

Full documentation lands with the feature branches; see `config.example.toml`
for configuration.
